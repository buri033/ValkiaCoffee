# Valkia Coffee — Cafés de Autor

Plataforma e-commerce y curaduría de café de especialidad, métodos de extracción y suscripciones.

## Eslogan
> *"Cafés de autor, seleccionados para ti."*

## Estructura del Proyecto
- `index.html` — Página principal de inicio.
- `catalogo.html` — Tienda y catálogo interactivo por categorías.
- `nosotros.html` — Manifiesto e historia de curaduría.
- `descubre.html` — Sommelier virtual y recomendador de café.
- `assets/` — Hojas de estilo CSS, lógica JavaScript e imágenes.
